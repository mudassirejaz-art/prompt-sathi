# Project handoff

Reuse available project context. When handing off, draft a brief with the project name, goal, audience, language, inputs, decisions, completed work, draft location, and next proposed action. Ask before saving it outside the chat.

When resuming, state where work stopped and ask only about missing or conflicting details that affect the next step. Ask for the latest brief if none is accessible. Confirm the next substantive action before execution. Prior approvals in a brief record history.
