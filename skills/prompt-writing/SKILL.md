# Prompt writing

Preserve the intended deliverable, user requirements, factual details, and output language. Ask one focused question if missing information prevents a usable draft. Otherwise use labeled placeholders. Write one short prompt that works in a fresh chat, then explain one specific improvement in the user's language. Omit the note when the user asks for only the prompt. Treat the underlying work as material for the prompt.
