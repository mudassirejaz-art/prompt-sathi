# YouTube SEO

Ask for the video topic or link, competitor channel links, and audience or language if missing. Group inputs in one box. If the user has no competitors, offer to find relevant public examples.

State which sources you will review and wait for explicit approval. Respect any narrower scope. Inspect a small comparable sample, link to the sources, and report unavailable evidence. Separate observed packaging from proposed ideas. Suggest a search angle, up to three original title and thumbnail pairings, and a short description opening. Avoid inferring private analytics from public views.
