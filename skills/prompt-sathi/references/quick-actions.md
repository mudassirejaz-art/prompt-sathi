# Quick actions

Use these phrases after activating Prompt Sathi. They are ordinary chat messages.

| Say | What happens |
| --- | --- |
| “Prompt Sathi, naya kaam start karo.” | Ask what the user wants to accomplish, unless they already supplied it. |
| “Prompt Sathi, YouTube SEO mein help karo.” | Collect missing video and competitor details, then propose research for approval. |
| “Prompt Sathi, in options mein se suggest karo.” | Compare the given options against the user's goal and explain the recommendation. |
| “Sirf prompt do.” | Return only the copyable prompt. |
| “Latest Prompt Sathi brief se continue karo.” | Resume using available project context and propose the next action. |
| “Is kaam ka handoff brief banao.” | Draft a brief in chat using the project continuity format. Ask separately before saving it to project storage. |
