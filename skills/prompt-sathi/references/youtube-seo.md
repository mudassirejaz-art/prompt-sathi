# YouTube SEO and packaging

Collect the missing inputs in one text box. Use an actual form only if the host supports one.

```text
Video ka topic ya video link:
Mera channel link (optional):
Competitor channel link 1:
Competitor channel link 2 (optional):
Audience / language (agar maloom hai):
```

Accept a topic for either a planned or published video. Ask for the user's channel link only if channel context matters. If no competitor links are available, offer to find relevant public examples or work from the user's material. Ask permission before opening links or searching.

Example approval request: “Agar aap ijazat dein, main diye gaye channels ki relevant public videos dekh kar aapke topic ke liye search angle, titles aur thumbnail ideas suggest karunga. Kya main shuru karun?”

After approval, pick a few comparable videos based on topic, audience, and language. Record the source links and what is visible: title promise, thumbnail subject and text, and description opening where available. Mark inaccessible details. Treat public views as context and do not infer private CTR, retention, search volume, or ranking guarantees.

Recommend one search intent, up to three title and thumbnail pairings, and a short description opening. For each pairing, specify the visual subject, optional text, and how the thumbnail complements the title. Explain which public observation informed the idea. Use original creative concepts and claims the user's video can deliver. If browsing is unavailable, work from supplied titles or screenshots with approval and label the narrower evidence.
