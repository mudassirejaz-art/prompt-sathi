# YouTube SEO and packaging

## Choose the workflow

| Request | Inputs to reuse or ask for | Deliverable |
| --- | --- | --- |
| Improve this video | Topic or link, audience, confirmed content | One recommended title and thumbnail pair, search intent and a description opening |
| Audit my channel | Channel link, growth goal, optional Studio export | Channel snapshot, three priorities and the metric or observation behind each |
| Find what works in my niche | Niche, approved competitors, format and date window | Sourced competitor sample, outliers where measurable and three original ideas |
| Plan and script my next video | Selected idea, creator voice, confirmed facts, upload capacity | Hook, script or outline as requested, packaging and a realistic production schedule |

Keep the channel, niche, audience, language, voice examples, competitor links, and upload capacity in the project brief when supplied. Confirm before saving changes. Reuse this profile across routes. For a complete plan, deliver the approved audit and scan first. Recommend one idea, then confirm the choice before investing in its full script. Show a publishing checklist and dates only when requested and feasible.

When the request could mean either one video or a whole channel, ask which one first. Tie titles and description claims to the user's confirmed video content. Label unconfirmed ideas as provisional.

Collect the missing inputs in one text box. Use an actual form only if the host supports one.

```text
Video ka topic ya video link:
Mera channel link (optional):
Competitor channel link 1:
Competitor channel link 2 (optional):
Audience / language (agar maloom hai):
```

Accept a topic for either a planned or published video. Ask for the user's channel link only if channel context matters. If no competitor links are available, offer to find relevant public examples or work from the user's material. Ask permission before opening links or searching.

Example approval request: “Agar aap ijazat dein, main diye gaye channels ki relevant public videos dekh kar aapke topic ke liye search angle, titles aur thumbnail ideas suggest karunga. Kya main shuru karun?”

After approval, pick a few comparable videos based on topic, audience, and language. Record the source links and what is visible: title promise, thumbnail subject and text, and description opening where available. Mark inaccessible details. Treat public views as context and do not infer private CTR, retention, search volume, or ranking guarantees.

For a competitor scan, record the channel, date window, format, sample size, publication date, public views and source URL. Separate Shorts and long-form and compare videos of similar age where possible. If at least five comparable uploads are available for a channel, calculate each video's views divided by that channel's sample median. Use 2× as a screening threshold and label it as a heuristic. If the baseline is unavailable, report observations without an outlier label. Treat likely reasons as hypotheses. Keep all searches and visual references inside the approved sources.

When approval names only a YouTube channel and its videos, restrict evidence to those YouTube pages. Ask before using third-party trackers, mirrors, articles, or image references. If a metric is unavailable on the approved pages, mark it unavailable and continue with the evidence you have.

For a channel audit, use supplied Studio data for CTR and retention when available. Distinguish the observed metric from the proposed fix. With only public data, audit visible packaging and cadence and state the limits.

Recommend one search intent, up to three title and thumbnail pairings, and a short description opening. For each pairing, specify the visual subject, optional text, and how the thumbnail complements the title. Explain which public observation informed the idea. Use original creative concepts and claims the user's video can deliver. If browsing is unavailable, work from supplied titles or screenshots with approval and label the narrower evidence.

Mark one pair as recommended. Before returning it, check that the title makes a specific promise early, the thumbnail adds visual information, and neither promises content the video lacks. Compare the thumbnail text with the title, including repeated phrases or numbers that convey the same information. Remove redundant thumbnail text or replace it with a distinct detail. For production, make the opening deliver on that same promise. Use the creator's confirmed voice and facts. Flag ideas and claims still awaiting confirmation. Keep publishing separate from drafting and request explicit approval before any upload or account change.
