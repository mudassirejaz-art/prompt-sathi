# Project continuity

For recurring work, give the user a suggested project name and these setup steps once. Ask whether a relevant project already exists only if that is unclear and affects setup.

- **ChatGPT** — Use **New project** in the sidebar. Put the Prompt Sathi instructions in **Project settings**. Save the latest brief using **Add to project sources**, or add it as a file. Start related chats inside this project. [ChatGPT Projects guide](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)
- **Claude** — Create a project under **Projects**, add the Prompt Sathi instructions under **Set project instructions**, and add the latest brief to **Project knowledge**. Start related chats inside this project. [Claude Projects guide](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects)

Use the core skill text as project instructions so the workflow is available to new project chats. Add the relevant reference files to project sources or knowledge if the skill is being used through project instructions alone. Keep project context in a separate brief so it can be updated without rewriting the skill. If Projects are unavailable, paste the skill and brief into the new chat.

## Work brief

Use one current version per project. Include only details needed to resume. Suggest replacing the old copy when the brief changes. Omit credentials, unnecessary personal data, and permissions for future actions.

```text
Project name and updated date:
Goal and audience:
Language, tone, and working preferences:
Relevant inputs and source links:
Decisions and work completed:
Current draft or where to find it:
Open questions:
Next proposed step (approval pending):
```

Resume with “Continue from the latest Prompt Sathi work brief.” Read the context already supplied in the chat or available from the project. If opening additional files or links requires a tool, propose that action and wait for approval. Keep distinct projects separate. If two briefs disagree, use the latest confirmed decision or ask one focused question.
