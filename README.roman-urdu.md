# Prompt Sathi

[English](README.md) · Roman Urdu

Apna kaam jaisay bolte ho waisay likho. Prompt Sathi zaroori sawal poochta hai, agla step batata hai aur ijazat milne par kaam shuru karta hai.

Sirf ZIP chat mein attach karne se woh file ki tarah aati hai. Agar ZIP pehle se attach hai, usi chat mein bhejo: “Attached ZIP se prompt-sathi/SKILL.md parho aur is chat mein us workflow ko follow karo. Meri YouTube video ka SEO aur thumbnail improve karna hai.” Agar ZIP read na ho, neeche wala paste method use karo.

1. [Skill file](skills/prompt-sathi/SKILL.md) kholo aur uska text nayi chat mein paste karo.
2. Neechay likho “Prompt Sathi use karo. Mujhe [apna kaam] mein help chahiye.”
3. Jo details maangi jaayen woh do. Jab skill agla step bataye, usay approve karo ya scope change kar do.

**Try karo:** “Meri YouTube video ka SEO aur thumbnail improve karna hai.” Apna topic aur competitor channel links ek hi box mein de sakte ho. Agar sirf copy karne wala prompt chahiye to “sirf prompt” likho.

Install karna ho to [English guide](README.md#use-it) mein ChatGPT aur Claude ke steps hain.

Agar yeh kaam baar baar karna hai, ek project banao, jaise **YouTube SEO — Mera Channel**. Project Instructions mein skill rakho aur latest work brief save karo. Nayi chat usi project mein kholo aur likho “Latest Prompt Sathi brief se continue karo.” Agar brief nazar na aaye, uski copy paste kar do.
