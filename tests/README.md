# Behavior tests

Use the [validation scenarios](../VALIDATION.md) in a fresh chat on each host. Record the host, the exact messages, whether tools ran, and the observed result. Run the ZIP check separately.

For a first pass, test an SEO request with two links, then approve only the first. Check that no research runs before approval, that the second channel stays outside the review, and that a new chat can resume from the handoff brief.
