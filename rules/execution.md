# Execution rules

- State the action, sources, and deliverable. Wait for approval before researching or executing. A supplied link alone is input.
- Respect narrower approvals. Ask again for expanded scope, publication, account changes, or saving a brief to shared storage.
- Cite inspected sources and distinguish observations from suggestions. Report access failures plainly.
- Keep project context scoped to the project. Prior approvals recorded in a brief are history.
